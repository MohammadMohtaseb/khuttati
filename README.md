# خُطّتي

الواجهة العامة لموقع [خُطّتي](https://khuttati.pages.dev): تسجيل الدخول باستخدام Google، وتسجيل الوجبات والتمارين والقياسات والصور لكل حساب على حدة. الواجهة عربية ومتجاوبة مع الهاتف والكمبيوتر.

## التشغيل المحلي

يتطلب Node.js 22.12 أو أحدث. انسخ `.env.example` إلى `.env.local` وضع رابط مشروع Supabase ومفتاح **publishable** فقط، ثم:

```bash
npm ci
npm run dev
```

`npm run build` ينتج مجلد `pages-dist/` الجاهز للرفع إلى Cloudflare Pages. هذا هو مجلد النشر العام الوحيد. يحتاج التطبيق إلى مشروع Supabase مجهّز بجدول التسجيلات وسياسات عزله؛ يوضّح `supabase/schema.sql` الجزء العام للبيانات والملفات الخاصة بكل مستخدم.

الكود المنشور يتوقع أيضًا دالتي `has_private_plan` و`is_plan_owner` وجدول `plan_shares` في مشروع Supabase الحالي. إعداد الوصول للخطة الخاصة غير مضمّن هنا؛ عند استخدام مشروع Supabase جديد يلزم إنشاء هذه الدوال والسياسات أو تعطيل بطاقة الخطة والمشاركة في الواجهة.

## خصوصية الخطة الشخصية

الملفان الأصليان PDF، وصور صفحات التمرين، وشفرة الخطة الشخصية غير موجودة في هذا المستودع العام أو حزمة Cloudflare. تُخزّن الخطة في bucket خاص على Supabase، ولا تُحمّل إلا بعد التحقق من حساب المالك أو من مشاركة أنشأها المالك. بيانات التمارين والوجبات التي يسجّلها المستفيد تبقى في حسابه المنفصل. إعدادات ملكية الخطة ومحتواها تُدار خارج المستودع العام.

لا تُضف مفاتيح Supabase السرية أو ملفات الخطة أو `.env.local` إلى Git.

## بدائل الوصفات

قسم «بدائل وصفاتي» يستخدم Cloudflare Workers AI لاقتراح الوصفة، ثم يحسب السعرات والماكروز من بيانات USDA FoodData Central المنشورة (SR Legacy 2018 وFoundation 2026) أو قيم الملصق التي يدخلها المستخدم. تعرض الواجهة مقادير نيئة وقيمًا مطبوخة منفصلة، مع تعديل الوزن الفعلي بعد الطبخ. تُحفظ الوصفة في حساب Supabase عند اختيار الحفظ. للنشر، اربط Workers AI باسم AI في Cloudflare Pages. ملفا `_worker.js` و`usda-sr-legacy-2018.json` يُنتجان داخل `pages-dist` عند البناء؛ لا يحتاج الموقع مفتاح USDA أثناء التشغيل. يمكن إعادة توليد قاعدة الغذاء المختصرة بواسطة `scripts/build-usda-index.mjs` بعد تنزيل مجموعتي JSON الرسميتين من [USDA](https://fdc.nal.usda.gov/download-datasets/) ووضعهما في `release/usda/sr/` و`release/usda/foundation/` بالأسماء الموضحة في الشفرة.
